# CMT_intronic_pipeline
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Repositorio donde se almacenarán los scripts y recursos adicionales correspondientes al proyecto "Desarrollo de un pipeline bioinformático para el análisis de variantes intrónicas en la enfermedad de Charcot-Marie-Tooth".

En la carpeta "Pipeline_preliminar" se encuentran los scripts y archivos utilizados en la obtención de los resultados preliminares.
